# Lab vault home

Read [setup](README.md), open [the test drawing](testing.md) in Excalidraw view, and run the generated `LayerManager` script from Excalidraw's script controls. Its folder is [Excalidraw/Scripts](Excalidraw/Scripts/README.md).

The maintained [manual matrix](../../packages/obsidian-excalidraw-layer-manager/docs/project/2026-04-16-layer-manager-manual-verification-matrix.md) and [current closeout](../../packages/obsidian-excalidraw-layer-manager/docs/project/2026-09-07-layer-manager-closeout.md) are repository-relative development links; when the vault is copied alone, consult them in the source checkout.

This is a disposable proving ground. Generated bytes, a visible panel, and a completed checklist are not substitutes for versioned verification evidence. Do not test destructive operations on personal notes.
